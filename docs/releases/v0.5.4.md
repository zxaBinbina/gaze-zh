# Gaze 中文版 v0.5.4

本版同步上游至 `d0e4622`，合并 64 个上游提交。新增首次设置向导、可选注视检测和摄像头组合回退，并改善各桌面的录入、设置及错误恢复。保留中文分支独立版本号、中文终端对齐、PAM/KRDP 登录兼容逻辑与分组件发行包。

## 更新内容

- **首次设置与命令行**：新增 `gaze setup`，依次检查摄像头、录入人脸、测试识别与桌面集成。配置向导按类别编辑草稿，检查更改后保存；模型切换会提示重新采集。`gaze test` 默认显示简洁结果，`--verbose` 显示指标；`gaze doctor --verbose` 显示包括可选功能在内的全部检查。
- **注视检测**：新增 `auth.require_attention`，要求睁眼正对摄像头后才完成匹配，默认关闭。眼部模型不可用时会拒绝人脸认证并显示恢复提示。
- **摄像头回退**：主组合未获得可用人脸时，可依次尝试最多三组 `[[cameras.fallback]]`。用 `gaze add-face <name> --camera 1` 或 `gaze refine-face <name> --camera 1` 为对应组合录入；`0` 表示主组合。保留物理来源校验和虚拟 RGB 摄像头的显式启用限制。
- **图形界面与桌面**：改善后台重连、摄像头扫描、重复名称处理、录入超时与重试、取消确认、暂停期间预览、识别失败说明及自动保存反馈。GNOME 设置显示录入状态与引导；KDE 修复开关绑定、活体阈值精度和录入倒计时。
- **密钥环与卸载**：诊断 oo7 密钥环未解锁可能造成的凭据丢失。卸载会传播软件包事务错误并停止删除剩余配置和人脸数据；中文步骤判断与 `gaze-zh` 核心包移除同步修正。
- **汉化与安装**：补齐新增 GUI、CLI、注视检测、回退摄像头、GNOME、KDE 及卸载提示的简体中文。仓库安装脚本采用本项目官网的中文组件菜单与发行包校验逻辑，并等待首次启动就绪、提供设置向导入口；安装脚本不再重启 polkit。命令、配置值、协议标识和 JSON 字段保持兼容。
- **构建**：更新 Rust 依赖；ONNX Runtime 升级到 1.32.0，从 Microsoft NuGet 包提取运行库并校验固定 SHA256。

## 升级与下载

软件版本为 **0.5.4**，安装包修订号为 **1**。从 v0.5.3 升级时，请更新核心程序及已安装的 GUI、桌面集成组件，再重启系统或重新登录。已有的人脸数据无需清空；切换识别模型时需为已有档案重新采集。

附件按系统与 CPU 架构分为八份压缩包：Ubuntu 24.04（amd64/arm64，amd64 同时适用于 Linux Mint 22）、Fedora 44/45（x86_64/aarch64）、openSUSE Tumbleweed（x86_64）及 Arch Linux（x86_64），另附 `SHA256SUMS`。每份包含核心程序、GUI、KDE、GNOME、Cinnamon、Hyprlock 和 Omarchy 七个独立组件。

请按系统与架构下载，校验后按包内中文 README 安装所需组件。中文安装器的推荐仅作标记，由用户选择方案；无人值守需明确指定 `--profile`。Omarchy 仍需 4.5.0 或更新的兼容版本。标准安装包的 KRDP 范围沿用此前版本，详见 [KRDP 构建说明](https://github.com/zxaBinbina/gaze-zh/blob/main/docs/krdp-fix.md)。
