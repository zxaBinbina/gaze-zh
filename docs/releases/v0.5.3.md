# Gaze 中文版 v0.5.3

本版同步上游至 `3223094`，合并 38 个上游提交，加入 libcamera 与桥接摄像头支持、更多认证失败诊断、oo7 密钥环和 Omarchy 4.5 兼容更新。保留中文版独立版本号、中文界面与终端排版、KRDP 登录兼容逻辑及中文安装器。

## 更新内容

- **摄像头**：支持 `libcamera:<名称>` 来源，改善 Intel IPU6/IPU7 与 SoC 平台摄像头兼容性；支持验证特权红外桥接的物理来源。虚拟 RGB 摄像头需要在配置文件中明确启用，默认仍拒绝；允许非特权进程写入时会显示风险提示。
- **认证安全**：红外摄像头断开后，仅 `or` 策略允许继续用 RGB 验证；胁迫锁定只在输入密码完成认证后清除，其他免密码认证不会解除锁定。
- **图形界面与命令行**：显示人脸测试拒绝、光线过暗、未检测到人脸、录入启动失败和设置授权失败的具体原因。录入与配置修改通过 polkit 请求密码，并在进入终端采集界面前完成授权；已发送的写入操作不再显示无效的取消提示。
- **密钥环与桌面**：支持 oo7 密钥环令牌交接；更新 KDE PAM 临时文件处理方式；同步 Omarchy 4.5 锁屏、指纹重试和视频背景支持。
- **汉化与打包**：补齐新增摄像头、桥接、认证诊断、Omarchy 指纹与超时提示，以及安装升级警告的简体中文；保留配置键、协议标识、命令和 JSON 字段，扩展汉化与 libcamera 错误识别回归检查。

## 升级与下载

软件版本为 **0.5.3**，安装包修订号为 **1**。从 v0.5.2 升级时，更新核心程序及已安装的 GUI、桌面集成组件，随后重启系统或重新登录。已有的人脸数据无需清空，用户自定义名称保持原样。

**Omarchy 用户请先升级至 4.5.0 或更新的兼容版本。** 本版插件基于 Omarchy 4.5.0；旧版用户应在已解锁桌面中升级 Omarchy 并运行 `gaze-omarchy enable`，或先运行 `gaze-omarchy disable` 恢复原版锁屏。更新后运行 `gaze-omarchy doctor` 检查兼容性。

附件按系统和 CPU 架构分为八份压缩包：Ubuntu 24.04（amd64/arm64，amd64 同时适用于 Linux Mint 22）、Fedora 44/45（x86_64/aarch64）、openSUSE Tumbleweed（x86_64）和 Arch Linux（x86_64），另附 `SHA256SUMS`。每份包含核心程序、GUI、KDE、GNOME、Cinnamon、Hyprlock 和 Omarchy 七个独立组件。

请按系统和架构下载，校验后按照包内中文 README 安装所需组件。也可使用[中文安装指南](https://zxabinbina.cc.cd/projects/gaze/guide/installation)中的安装器。
