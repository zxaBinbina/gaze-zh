# Gaze 中文版 v0.4.1-zh.2

同步 2026-10-29 合并的上游更新，并将下载附件整理为八份按发行版和架构区分的压缩包。软件版本仍为 `0.4.1`，安装包修订号从 `1` 提升到 `2`。

## 更新内容

- 合并上游至 `5fcec36`，修复 GNOME 人脸认证重试时密码提示的保留行为。
- ONNX Runtime 更新到 `1.31.1`，同步 Rust 依赖锁文件及构建环境更新。
- 保留中文界面、PAM 提示及 KRDP 登录兼容逻辑。
- 每个发行版与架构组合提供一份独立压缩包，内含七个独立组件，附安装说明、构建来源和校验值；发行页另附总 `SHA256SUMS`。
- 中文分支统一使用 `Packages and Release` 工作流，避免同时运行上游 CD 的整套发布流程。

补充发布：Ubuntu ARM64、Fedora 44/45 AArch64 与 Fedora 44 x86_64 包使用同一发布源码 `713d18f` 和包修订号 `0.4.1-2` 构建。ARM 和 x86 各自下载、安装；原有四份 x86 附件保留。

## 选择下载

| 文件名中的系统标识 | 适用构建环境 | 内容 |
| --- | --- | --- |
| `ubuntu-24.04-amd64` | Ubuntu 24.04 / Linux Mint 22，amd64 | DEB 组件包 |
| `ubuntu-24.04-arm64` | Ubuntu 24.04，arm64 | DEB 组件包 |
| `fedora-44-x86_64` | Fedora 44，x86_64 | Fedora RPM 组件包 |
| `fedora-44-aarch64` | Fedora 44，aarch64 | Fedora RPM 组件包 |
| `fedora-45-aarch64` | Fedora 45，aarch64 | Fedora RPM 组件包 |
| `fedora-45-x86_64` | Fedora 45，x86_64 | Fedora RPM 组件包 |
| `opensuse-tumbleweed-x86_64` | openSUSE Tumbleweed，x86_64 | openSUSE RPM 组件包 |
| `archlinux-x86_64` | Arch Linux，x86_64 | Arch 组件包 |

Fedora 和 openSUSE 的 RPM 分开打包；Ubuntu 24.04 的 DEB 不作为其他 Debian/Ubuntu 版本的通用包。其他系统可参考[中文安装指南](https://zxabinbina.cc.cd/projects/gaze/guide/installation)选择上游软件源或自行构建。

下载对应压缩包与 `SHA256SUMS`，校验下载文件后解压。在解压目录执行 `sha256sum -c SHA256SUMS`，再按 `README.md` 安装主程序 `gaze-zh`、可选的 GUI，以及当前桌面对应的集成包。不要一次安装全部桌面组件。

GUI 和桌面集成与核心包各自承担不同功能，没有重复载荷。此次合并的是下载附件，仍保留按需安装和卸载组件的能力。

## KRDP 修复范围

这些标准组件包包含 PAM 层的 KRDP 登录兼容逻辑。Fedora 44 / KRDP 6.7.5 专用的私有画面冻结修复库属于单独的历史合并构建，未包含在本次附件中；构建说明见 [docs/krdp-fix.md](../krdp-fix.md)。
