# Gaze 中文版 v0.5.1

本版修复 v0.5.0 认证成功后仍显示 `Face Verified.` 的遗漏。终端及图形认证现在显示“人脸已验证。”，确认、密码输入、失败、光线不足和超时提示也统一为简体中文，保留原有布局。

## 更新内容

- **认证提示**：补齐 PAM 顺序、同时认证和密码失败后重试路径的中文提示，包括按键确认及无终端时的确认提示。
- **桌面集成**：GNOME、Cinnamon 和 Omarchy 可识别中文及旧版英文 PAM 消息。确认按钮仍发送对应协议要求的回复；显示提示本身不会确认认证。
- **后台与诊断**：汉化传到界面的摄像头、模型、权限、人脸存储和加密错误，以及 Gaze 自身的诊断日志说明。
- **安装与配置**：汉化软件包说明、安装和卸载提示、安装器、配置模板及 NixOS 选项说明；补齐命令行帮助附注和新录入人脸的默认名称。
- **防止再次遗漏**：新增 `AGENTS.md`，要求每次拉取或合并上游后检查可见文字，特别检查新增、移动和重命名的文件。新增认证提示回归检查并接入 CI。

## 升级与下载

软件版本为 **0.5.1**，安装包修订号为 **1**。中文版继续使用独立版本号；本版上游基础仍为 `cc74790`。

从 v0.5.0 升级时，更新核心程序及已安装的 GUI、桌面集成组件，随后重启系统或重新登录，让 PAM 和桌面扩展加载新版本。已有的人脸数据无需清空，用户自定义的人脸名称不会被翻译。命令名称、配置键值、协议标识及 JSON 字段保持兼容。

附件提供 Ubuntu 24.04（amd64/arm64，amd64 同时适用于 Linux Mint 22）、Fedora 44/45（x86_64/aarch64）、openSUSE Tumbleweed（x86_64）和 Arch Linux（x86_64）共八份压缩包，另附 `SHA256SUMS`。每份包含核心程序、GUI、KDE、GNOME、Cinnamon、Hyprlock 和 Omarchy 七个独立组件。

请按系统与架构下载，校验后按照包内中文 README 安装。也可使用[官网安装器](https://zxabinbina.cc.cd/projects/gaze/guide/installation)选择组件。
