# Gaze 中文版 v0.5.2

本版同步上游至 `1d21641`，合并 32 个上游提交，加入有序 RGB 摄像头来源回退、默认显示诊断的测试命令及 KDE Plasma 6.8 认证兼容更新。保留原有中文界面与排版，并补齐新增、移动代码中的认证、配置、诊断和安装卸载提示。

## 更新内容

- **摄像头**：`cameras.rgb` 支持按顺序尝试多个来源，例如 `["usb:046d:081b", "primary"]`；仅在打开失败时尝试下一个来源。修复部分 V4L2 设备无法枚举的问题，认证时拒绝虚拟或回环 V4L2 节点，并在认证策略允许时于红外来源丢失后继续使用 RGB。
- **命令行**：`gaze test` 默认显示摄像头、识别及各光谱的详细诊断。旧命令 `gaze auth` 和 `--verbose` 选项继续兼容，`--silent` 仍通过退出码报告结果。测试命令不授予权限，也不验证 PAM 集成；已启用的胁迫检测可能触发持续锁定。
- **认证与桌面**：更改 Gaze 设置或人脸数据时，明确显示需要密码的中文提示，并兼容旧版中文和上游英文拒绝消息。修复 KDE 认证重试及 Plasma 6.8 的锁屏服务选择，GNOME 扩展禁用后不再响应守护进程重启。
- **可靠性**：修复 GDM 配置任务使用的运行时、人脸模板编号冲突及胁迫检测计时；卸载时保留 Hyprlock 配置的符号链接，并限制 authselect 恢复操作的范围。
- **汉化与兼容**：补齐相机回退、管理员密码、后台错误及 KDE 迁移提示的简体中文，扩展汉化回归检查；保留 KRDP 登录兼容逻辑和原有配置、协议及 JSON 标识。

## 升级与下载

软件版本为 **0.5.2**，安装包修订号为 **1**。中文版继续使用独立版本号。

从 v0.5.1 升级时，更新核心程序及已安装的 GUI、桌面集成组件，随后重启系统或重新登录。已有的人脸数据无需清空，用户自定义名称保持原样。升级至 Plasma 6.8 后，可运行 `sudo gaze-kde-pam enable` 重新配置锁屏集成，再用 `gaze doctor` 检查。

附件按系统和 CPU 架构分为八份压缩包：Ubuntu 24.04（amd64/arm64，amd64 同时适用于 Linux Mint 22）、Fedora 44/45（x86_64/aarch64）、openSUSE Tumbleweed（x86_64）和 Arch Linux（x86_64），另附 `SHA256SUMS`。每份包含核心程序、GUI、KDE、GNOME、Cinnamon、Hyprlock 和 Omarchy 七个独立组件。

请按系统和架构下载，校验后按照包内中文 README 安装所需组件。也可使用[中文安装指南](https://zxabinbina.cc.cd/projects/gaze/guide/installation)中的安装器。

## 验证

- 完整 Rust 测试：975 项通过；3 项需要专用 OpenVINO 或 TPM 环境的测试按原设置跳过。
- 汉化 14 项、GNOME 176 项、Cinnamon 110 项、KDE 192 项、KDE 设置页 4 项检查通过。
- 打包工具 8 项测试通过；真实 Linux-PAM 的 GDM 密钥环、失败锁定、greetd 交接及 96 个 KDE/KWallet 场景通过。
- PAM 动态库链接、Rust 格式及安装脚本语法检查通过。

标准安装包的 KRDP 范围沿用此前版本，详见 [KRDP 构建说明](https://github.com/zxaBinbina/gaze-zh/blob/main/docs/krdp-fix.md)。
