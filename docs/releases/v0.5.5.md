# Gaze 中文版 v0.5.5

本版同步上游 `main` 至 `2ae26a0`，合并 61 个提交。保留中文命令行和安装器、PAM 中文提示、KRDP 登录兼容逻辑，以及 `gaze-zh` 核心包和独立桌面组件。

## 更新内容

- 新配置默认要求确认 `sudo`、`su`、Polkit 等提权场景的人脸匹配，已有显式配置仍然生效。切换到其他用户的 `su` 使用密码。远程提权会进一步检查 SSH 会话，PAM 也会在撤销提示时清理尚未读走的自动换行。
- 后台将模板与账户 UID 关联。更换识别模型后，GTK 和命令行会列出需要重新采集的人脸。新名称不能包含不可见字符或文本方向控制字符，且最长 255 字节。
- GTK 主窗口更新了录入、识别和设置清单布局，后台重启后可自动重连。命令行配置可按 Esc 返回上一级，放弃未保存的草稿前会询问确认。摄像头掉线、配置错误、模型不匹配和卸载提示已补齐简体中文。
- 引入 GTK、GNOME、Cinnamon、KDE 和软件包元数据的翻译目录。GTK 在英文和未支持的桌面语言下默认显示简体中文。KDE 卸载通过原有辅助工具恢复 PAM，GNOME 诊断会检查用户手动开启的 GDM 人脸登录。
- gazed 通过 D-Bus 报告就绪，切换至需要其他运行时的推理后端时可自动重启。Arch Linux 包静态链接 OpenCV，减少 OpenCV 滚动升级时的库版本问题。旧的 `pam_gaze_grosshack.so` 入口使用指向 `pam_gaze.so` 的兼容链接。

## 升级与下载

软件版本为 **0.5.5**，安装包修订号为 **1**。升级时请同时更新核心包和已安装的 GUI、桌面集成组件，然后重新登录或重启。若 GTK 或命令行提示档案使用了其他模型，请为相应档案补充采集，再测试识别。

附件按系统与 CPU 架构分为八份压缩包，覆盖 Ubuntu 24.04（amd64/arm64，amd64 同时适用于 Linux Mint 22）、Fedora 44/45（x86_64/aarch64）、openSUSE Tumbleweed（x86_64）和 Arch Linux（x86_64）。每份包含核心程序、GUI、KDE、GNOME、Cinnamon、Hyprlock 和 Omarchy 七个组件。请使用随附的 `SHA256SUMS` 校验下载文件，并按包内中文 README 安装需要的组件。
