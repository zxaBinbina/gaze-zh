# Gaze 中文版 v0.5.0

本版补齐图形界面、命令行和桌面设置的简体中文，沿用原有窗口尺寸、控件顺序与终端布局。中文版从本版起采用独立版本号；本次基于上游 Gaze 0.4.1，并同步至 `cc74790`。

## 更新内容

- **图形界面汉化**：覆盖 GTK 人脸管理、录入与补充采集、重命名和删除、认证结果、设置及提示信息；同步 KDE 原生设置页和 GNOME 扩展设置文案。
- **命令行汉化**：覆盖命令帮助、参数错误、配置向导、人脸管理、认证、诊断、密钥环操作及卸载提示。保留 `gaze help`、嵌套帮助和 Shell 补全。
- **排版与输出**：中文及较长的人脸名称按终端显示列宽对齐；保留交互界面的样式，管道输出不强制插入颜色控制符，静默认证继续仅以退出码报告结果。
- **文档更新**：恢复中文 README，整理安装、构建、常用命令与故障排查说明。发布流程直接使用仓库内的中文发行版说明。
- **上游同步**：合并文档工具链、GitHub Actions 与 Ubuntu 构建镜像更新，保留中文分支现有的 PAM 提示和 KRDP 登录兼容逻辑。

## 版本与升级

本版软件版本为 **0.5.0**，安装包修订号为 **1**。版本号不再跟随上游；未来同步上游时，会在发行说明中单独注明同步范围。

可从中文版 `0.4.1-2` 升级到 `0.5.0-1`。命令名称、选项、配置键值、JSON 字段和 D-Bus 方法保持兼容；界面文字的中文化不会改变这些接口。升级无需清空已有的人脸数据。

下载并安装与当前系统及 CPU 架构匹配的核心包、GUI 和已使用的桌面集成组件，随后重启系统或重新登录，使服务和桌面组件加载新版本。安装方式见[中文安装指南](https://zxabinbina.cc.cd/projects/gaze/guide/installation)。

## 下载选择

附件按发行版与架构分为八份压缩包，每份包含七个可独立安装的组件：`gaze-zh`、`gaze-gui`、`gaze-kde`、`gaze-gnome-extension`、`gaze-cinnamon-extension`、`gaze-hyprlock`、`gaze-omarchy`。

| 文件名中的系统标识           | 构建环境 / 架构                     | 包格式 |
| ---------------------------- | ----------------------------------- | ------ |
| `ubuntu-24.04-amd64`         | Ubuntu 24.04 / Linux Mint 22，amd64 | DEB    |
| `ubuntu-24.04-arm64`         | Ubuntu 24.04，arm64                 | DEB    |
| `fedora-44-x86_64`           | Fedora 44，x86_64                   | RPM    |
| `fedora-44-aarch64`          | Fedora 44，aarch64                  | RPM    |
| `fedora-45-x86_64`           | Fedora 45，x86_64                   | RPM    |
| `fedora-45-aarch64`          | Fedora 45，aarch64                  | RPM    |
| `opensuse-tumbleweed-x86_64` | openSUSE Tumbleweed，x86_64         | RPM    |
| `archlinux-x86_64`           | Arch Linux，x86_64                  | Arch   |

下载对应压缩包与发行页的 `SHA256SUMS`，校验后解压；再在解压目录执行 `sha256sum -c SHA256SUMS`，按照包内 `README.md` 安装核心程序、可选 GUI 及当前桌面所需的集成。Fedora 与 openSUSE 的 RPM 分别构建，不能混用；ARM64 与 x86_64 分开下载。

官网安装器会按系统和架构匹配附件，再显示组件菜单；可选择“不安装 GUI，仅安装命令行”。

## 验证与范围

- 355 项相关 Rust 测试通过，涵盖核心、CLI、GTK GUI 和摄像头模块。
- 420 项 GNOME、Cinnamon、KDE 集成测试通过。
- CLI / GTK GUI 和 KDE 设置模块构建通过；已检查中文帮助、参数错误、终端列宽及 GTK 主窗口和设置页排版。

标准组件包保留 PAM 层的 KRDP 登录兼容逻辑。Fedora 44 / KRDP 6.7.5 专用的私有画面冻结修复库仍属于单独的历史构建，不包含在这些附件中；详见 [KRDP 构建说明](https://github.com/zxaBinbina/gaze-zh/blob/main/docs/krdp-fix.md)。
